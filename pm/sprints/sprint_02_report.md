## 2. Реализованный функционал

1. **Слой Domain (13 SP)**:
   * Неизменяемые финансовые Value Objects: `Money` с защитой валют и контролем округления, `Currency`, `IdempotencyKey`.
   * Сущности `Tenant`, `Plan`, `Subscription`, `Invoice`, `UsageRecord`.
   * Метод `Subscription.calculate_proration()`: точный математический расчет неизрасходованного остатка и доплаты при смене тарифа.

2. **Прикладной слой Use Cases (8 SP)**:
   * `SubscribeCustomerUseCase`: оформление подписки, учет триала, проверка ключа идемпотентности.
   * `ChangePlanUseCase`: смена плана с выпуском корректирующего счета на разницу сумм.
   * `RecordUsageUseCase`: фиксация событий потребления ресурсов.
   * `RunBillingCycleUseCase`: ночной биллинг с начислением за овердрафт квот и переводом в статус задолженности при отказе банка.

3. **Инфраструктурный слой и эмулятор (5 SP)**:
   * `FaultTolerantPaymentGatewayEmulator`: воспроизведение сетевых задержек, таймаутов (504), отклонений карт и фиксация транзакций по ключам идемпотентности.
   * In-Memory репозитории для быстрого тестирования бизнес-логики.

4. **Слой представления REST API (8 SP)**:
   * Эндпоинты `/api/v1/tenants`, `/api/v1/plans`, `/api/v1/subscriptions`, `/api/v1/usage`, `/api/v1/billing-cycle/run`.
   * Автоматическая генерация интерактивной документации OpenAPI / Swagger UI.
   * Интеграционные тесты `tests/integration/test_api.py`.
